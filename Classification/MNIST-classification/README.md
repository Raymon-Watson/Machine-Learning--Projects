# MNIST Classification

A multi-class classification problem for labelling a collection of 70,000 handwritten digits. This is a very common method to test new classification methods.

The purpose of this project is to understand better the various methods and measures of performance for a classification task.

## Notebooks

The analysis is contained in a single notebook: ```data_analysis.ipynb```. This notebook contains the following:
- Data loading and inspection
- Binary classification via Stochastic Gradient Descent (SGD)
- Multi-label classification via SGD, Support Vector Machine (SVM), and Random Forest
- Calculation and comparison of various metrics:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
  - ROC curve
  - AUC
  - Confusion matrix



## How To Run This Project
1. Clone repository into relevant project folder
2. Ensure jupyter notebook is installed, along with all relevant libraries (contained at the top of the jupyter notebook files)
3. Run the ```data_analysis.ipynb``` notebook
