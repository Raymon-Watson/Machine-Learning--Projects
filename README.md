# Machine Learning Projects

This repository contains a collection of machine learning projects I’ve worked on while learning data science and machine learning.

The projects are split into two main areas:

* **Classification**
* **Regression**

Each project focuses on working through a full machine learning workflow, from exploring and cleaning the data through to model training, tuning, and evaluation.

## Classification

Current classification projects include:

* **MNIST Digit Classification** — comparing several models for handwritten digit recognition, including SVM, KNN, Random Forest, Naive Bayes, and neural networks.
* **Titanic Survival Prediction** — using the Kaggle Titanic dataset to practise preprocessing, feature engineering, model comparison, and binary classification.

Common evaluation methods include accuracy, precision, recall, F1 score, ROC-AUC, and confusion matrices.

## Regression

Regression projects will be added as I work through different approaches to predicting continuous values.

These will include methods such as:

* Linear Regression
* Ridge and Lasso Regression
* Decision Trees
* Random Forests
* Support Vector Regression
* Gradient Boosting
* Neural Networks

Typical evaluation metrics will include MAE, RMSE, and R².

## Neural Networks

I’m also using this repository to gradually move from classical machine learning into neural networks and deep learning.

The first focus will be on:

* Fully connected neural networks
* Backpropagation and gradient-based optimisation
* Overfitting and regularisation
* Convolutional Neural Networks for image classification

MNIST provides a useful way to compare neural networks with more traditional machine learning models on the same problem.

The main goal of this repository is to build practical experience with machine learning while developing a better understanding of how different models work, when to use them, and how to evaluate them properly.

Over time, I plan to add more classification, regression, ensemble learning, neural network, and deep learning projects.
