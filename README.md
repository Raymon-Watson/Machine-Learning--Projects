# house-price--linear-regression

The aim of this project is to learn Python fundamentals for linear regression with application in data science. 



# Skills
The essential skills I want to learn within this project can be broken down into Python skills and Data/ML skills.
## Python 
- Variables, numeric types, strings, and booleans
- Lists, tuples, dictionaries, and sets
- if/elif/else
- for loops and basic comprehensions
- writing and calling functions
- imports and using library documentation
- basic pathlib paths

## ML
- DataFrame and Series
- Reading CSV and inspecting schema
- selecting, filtering, and sorting
- missing-value inspection
- summary statistics and distributions
- train/test split
- linear regression and regression metrics
